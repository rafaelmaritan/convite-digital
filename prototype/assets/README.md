# Assets do convite do Pedro

Os arquivos desta pasta foram recortados da imagem de referência fornecida para o projeto, sem usar fotografias externas nem redesenhar os personagens.

- `portrait-pedro.webp`: recorte da fotografia do Pedro, com máscara suave para integrar a foto ao papel.
- `hippo.png`: hipopótamo com jardineira azul.
- `giraffe.png`: girafa ocre com manchas.
- `fox.png`: raposa com vestido terracota.
- `dachshund.png`: dachshund terracota.
- `decor/olive-sprig.png`: ramo de folhas oliva.
- `decor/cloud.png`: nuvem azul acinzentada.
- `decor/sun.png`: sol terracota.

Os recortes dos personagens e dos ornamentos têm fundo transparente para se integrarem ao papel creme da página. A imagem completa de referência permanece fora do repositório; somente os recortes usados pelo frontend estão versionados.
